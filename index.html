Publish for all players

Put the game on GitHub Pages and collect every player's score in one shared leaderboard that all devices see. Scores are stored in a free Firebase Realtime Database.

Use a new Event ID for the live event so test scores stay separate. Anyone with the link can play, and anyone who knows the browser developer tools can read the answer key from the package. That is fine for an internal event.

Setup in 5 steps

  1. Open console.firebase.google.com and create a project. The free plan needs no card. Google Analytics can stay off.
  2. Go to Build, then Realtime Database, then Create Database. Pick any location and start in locked mode.
  3. Open the Rules tab, paste the rules below and click Publish.
  4. Copy the database URL shown at the top of the Data tab, paste it here and click Test connection, then Build upload package.
  5. Unzip the package. In your GitHub repository, upload game.json and the images folder next to index.html. Wait about a minute, then open the page address on a phone.
